# Star Defender

A simple browser shooting game built with HTML, CSS, and JavaScript.

## How to play

1. Open `index.html` in a browser, or serve the folder locally.
2. Press the Start button.
3. Move left and right with the arrow keys or `A`/`D`.
4. Press the space bar or click the canvas to shoot.
5. Survive as long as possible and score points.

## Local preview

If you want to serve it from a local web server:

```bash
cd shooting-game-website
python3 -m http.server 8000
```

Then open `http://localhost:8000` in your browser.

## Project files

- `index.html` – page structure
- `style.css` – visual design and layout
- `game.js` – gameplay logic and rendering
